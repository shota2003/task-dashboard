# 📊 Task Dashboard

A modern, responsive task management application built with **React**. This project was designed to help users organize their daily workflows, track task completion statuses, and maintain productivity through an intuitive interface.

## 🚀 Features
* **Task Management:** Create, read, update, and delete (CRUD) tasks seamlessly.
* **Filter & Sort:** Easily filter tasks by Status (All, Pending, Completed).
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
* **State Management:** Handled efficiently using React hooks (`useState`, `useEffect`).

## 🛠️ Tech Stack
* **Frontend:** React (JavaScript / JSX)
* **Styling:** CSS / Tailwind CSS *(choose which one you used)*
* **Build Tool:** Vite / Create React App *(choose which one you used)*

## 🏃‍♂️ Getting Started

To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the directory:**
   ```bash
   cd task-dashboard
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   *(Note: change to `npm start` if you used Create React App)*
